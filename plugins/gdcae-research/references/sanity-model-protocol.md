# Sanity Model 与科研验真

Sanity Model 是对某项研究用途已有验证依据的工程基准。先写明要支持的主张、工况和观测，再判断现有证据能支持到哪里。能够打开模型、读到一个数值或完成一次求解，各自只回答了一个有限的问题。

## 建立基准

可接收研究者已有模型，或由 Agent 根据几何、材料、边界条件和验证资料建立候选。两种入口使用相同的资格要求。记录模型版本、依赖、物理假设、单位、验证方法、误差限、适用范围及关键未知。当前插件只读比较已有小冲杆历史输入与公开曲线。

## 理解模型

逐项区分直接读到的事实、有依据的推断、未知和建议。例如，读到材料表后还要追踪它分配给哪个区域；从一个节点集读到反力，还要核对实例、分析步、方向和符号。INP 可用于核对求解定义，原生几何特征需要相应建模证据。历史 CSV 只代表已导出的量。分别记录文件识别、定义读取、关系重建、工程解释、受控修改和科研适用性验证的证据。

## 约定比较与修订

在研究合同中明确目标、基准、研究变量与范围、固定条件、观测选择器、验收阈值和资源预算。例如，研究夹持力时它可以变化；比较两张材料表时，夹持通常需要控制。派生候选应记录父基准、改动与不变量。超出原约定时记录修订理由、受影响的验证和研究者的明确确认，保留原合同及其证据。

## 解释结果与授权

变量可以包括材料、几何、Step、Load、Interaction 或扫描顺序，由研究问题和比较条件决定。遇到探索性失败，保存输入版本、操作、实际观测和未知，按授权与预算判断能否继续。

比较末点的同时检查全曲线、采样覆盖、插值、模型单位、警告及来源。误差小仍可能有多个相容的参数组合。用独立参考和有辨识力的验证试验检查材料主张。缺少依据时报告未知。合同确认、候选导出、Datacheck 和求解分别具有不同的操作范围；真实执行需要独立、具体的授权。
