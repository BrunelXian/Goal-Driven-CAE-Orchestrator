# GD-CAE orchestration language

**Project Main**: The single bound research coordination chat for one project.
It owns decomposition and change intake, not Solver authorization.

**Scoped Session**: A distinct specialist context bound to one project, role and
current task. It allows questions about that assignment without accepting new
engineering work independently of Main.

**Task Binding**: The fixed association of a task's project, role definition,
assigned evidence, permissions and configuration snapshot.

**Project Short Name**: A user-accepted navigation label shared by Main and its
specialist chats. It does not establish project identity or authority.

**Session UNKNOWN**: A host operation whose effect cannot yet be established
from its original request correlation. It does not authorize repeating creation.
