# INT-001: cross-system verification of a historical axial-bar run

VeriCAE 0.5.5 and AbqJobPilot 0.5.3 DEV were evaluated using a frozen, linear-elastic T3D2 model. Main dispatched scoped Task Cards to three existing Codex role conversations and read their replies. Results and Independent Validation each used the Desktop history MCP interface to read the environment, run, acceptance receipt and extraction record. They queried the same historical source independently.

The bar was aligned with global Y, with length 10 mm, area 1 mm² and Young's modulus 1000 N/mm². A load of −1 N acted on the free axial degree of freedom. The predicted tip displacement was FL/(EA) = −0.010 mm. The last increment of the static load step gave −0.010000000 mm in the historical DAT node table. The diagnostic output differed by 2.235174179 × 10⁻¹⁰ mm (relative error 2.24 × 10⁻⁸). Independent Validation checked the step mapping against the approved selector, the input and the DAT table.

Scientific verification passed for this displacement and load case. The solver verdict recorded COMPLETED and containment VERIFIED, with execution qualification REVIEW_REQUIRED. The ODB registration recorded TRUSTED_SOURCE. The original extraction receipt recorded FAILED. A later verdict recorded the extraction program as COMPLETED, with qualification REVIEW_REQUIRED and historical result integrity INSUFFICIENT. Exit semantics and the binding between the owner and the diagnostic output remained unresolved.

Overall verdict: **PARTIAL**. This study covers historical readback, four-role coordination and numerical verification. A fresh solve, a new execution grant and qualification of newly extracted outputs were outside its scope.

The [public replay](demo/README.md) reproduces the arithmetic from the frozen input and the published observations. Access to the original Desktop roles, MCP service and private execution records was part of the historical study.
