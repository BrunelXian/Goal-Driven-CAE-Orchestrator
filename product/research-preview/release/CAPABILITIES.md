# 能力与适用范围

本候选沿用 beta.1 的标准库 SP 分析组件，比较两份已知 INP 以及公开历史 ODB 提取 CSV，输出模型差异、曲线差值和来源限制。力与位移采用模型单位。解释器必须是已绑定的 Windows CPython 3.12.10。插件使用明确的项目读取清单，并将报告写入全新的项目外目录。

历史 beta.1 已通过单 Main 桌面正例及错误 CSV 拒绝测试。新身份 `gdcae-research@gdcae-research-agreements`、版本 `0.2.0-preview.4` 的独立桌面复验另行记录。案例中的 RC3 摘要标识历史曲线来源。

启用 schema 3 的新项目可使用安装态 Markdown 科研约定卡。概览、详情、差异和版本提示从 ResearchProject 的同一审计链重读。可明确提出、确认修订和声明历史归属。原生建模、自动多 Agent 派工、独立科研接受和真实求解循环仍待开发或验证。使用步骤见安装包内插件的 references/research-agreement.md。
