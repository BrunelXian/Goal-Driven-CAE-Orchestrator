# VeriCAE Research 0.5.5

This directory contains the Codex Native research plugin. The public checkout registers it as `vericae-research@vericae-public`. The repository README describes installation and the scope of INT-001.

Use [Initiate](skills/initiate/SKILL.md) to define the Research Contract, [Conduct](skills/conduct/SKILL.md) to resume a project and dispatch Task Cards, and [Setup](skills/setup/SKILL.md) to verify the current environment. Main owns the [research workspace](templates/research-project/README.md). Specialist roles return bounded artifacts and evidence for independent review.

The plugin supplies [role configuration templates](references/native-agents.md) and [model assignment guidance](references/adaptive-model-assignment.md). External AbqJobPilot connectivity and execution permissions are provisioned separately. Follow the [Desktop verification and recovery protocol](references/mcp-runtime-verification.md) after changing an MCP connection.
