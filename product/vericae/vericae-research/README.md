# VeriCAE Research 1.0.0

This is the Codex Native plugin packaged as `vericae-research@vericae-public` in the repository's local marketplace. The archive includes INSTALL.md and RELEASE_NOTES.md beside the marketplace catalog.

| Entry | Role |
|---|---|
| [Initiate](skills/initiate/SKILL.md) | Confirm the contract, draft a Research Card and prepare the workspace and Handoff. |
| [Conduct](skills/conduct/SKILL.md) | Resume the study, scope Task Cards and collect original replies in the existing role conversations. |
| [Setup](skills/setup/SKILL.md) | Inspect the current environment and report which capabilities the active conversation can use. |

Main owns the [research workspace](templates/research-project/README.md). The package includes [role configuration templates](references/native-agents.md) and [model assignment guidance](references/adaptive-model-assignment.md). External AbqJobPilot connectivity and execution permissions are provisioned separately. Follow the [Desktop verification and recovery protocol](references/mcp-runtime-verification.md) after changing an MCP connection.
